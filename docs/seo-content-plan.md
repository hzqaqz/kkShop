## 四、写作规范（每篇都照这个来）

1. **一个主关键词**，出现在：标题、H1、首个 H2、正文前 100 字、至少一个 H2
2. **篇幅** 1500–2500 字，H2 分 5–8 节，必要时加 H3
3. **内链** 至少 3 条：2 条指向产品页，1–2 条指向其他文章
4. **外链** 引用权威来源（WHO、EPA、ASHRAE 等），提升可信度
5. **结尾** 自然引出产品，不要硬广
6. **配图** 用真实场景图，alt 写描述性文字（不是堆关键词）

## 五、新增文章后要做的事

新文章发布后，除了写正文，还要更新两处代码，内链才会自动生效：

1. **`src/data/contentLinks.js`** — 给新 slug 加上 `tags` 和 `products`：
   ```js
   'your-new-article-slug': {
     tags: ['pets', 'air-purifier'],   // 决定「相关阅读」
     products: ['mw200', 'mw100'],     // 决定文末推荐产品
   },
   ```
2. **`src/data/blogArticles.js`** — 按现有格式添加文章数据（slug / title / date / coverImage / contentMarkdown）

> 加完跑一次 `npm run build`，新页面会自动进入预渲染和 sitemap 范围（sitemap 需同步补一行）。
