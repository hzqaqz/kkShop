# 首页轮播图出图规格（Meower 官网）

> 目的：让轮播图与 HTML 文案各得其所——图片不再被文案卡片遮挡，同时让标题文字能被 Google 读取。

---

## 一、最重要的一条：图内不要放文字

现在的 4 张轮播图把标题烘焙在图上（左上角的 "Meower Air Purifier / Cleaner Air. Happier Pet Homes."）。这带来三个问题：

| 问题 | 后果 |
|---|---|
| Google 读不到图片里的字 | 首页最重要的标题对 SEO 完全无效 |
| 图上没地方放 HTML 文案 | 只能把文案卡片压在图上，遮挡画面 |
| 改文案要重新出图 | 每次调整标题都得找设计师返工 |

**所以：官网用的版本，图内不要任何文字（标题、副标题、logo 都不要）。**
文字全部由网页代码渲染。需要带文字的版本，另外导一份给公众号/朋友圈用即可。

---

## 二、尺寸规格

| 项目 | 规格 |
|---|---|
| 画布尺寸 | **1800 × 1000 px**（横版，接近 16:9） |
| 最小可接受 | 1600 × 900 px |
| 色彩空间 | **sRGB**（不要用 Adobe RGB，浏览器会偏色） |
| 分辨率 | 72 dpi 即可（网页只看像素，不看 dpi） |

> 1800px 宽是因为网页上最大显示宽度是 1180px，留出余量给视网膜屏。
> 再大没有意义——只会让加载变慢。

---

## 三、构图要求（二选一）

### 方案 A：四周正常留白（推荐）

如果采用「文案放在轮播图**下方**」的布局，图片不需要预留特殊区域，按正常的好照片构图即可：

```
┌──────────────────────────────┐
│                              │
│        主体（产品 + 场景）      │
│                              │
└──────────────────────────────┘
   Pet-Friendly Air Purifiers...   [Explore] [Get a Quote]
```

- 主体居中或偏右
- 四周留出自然的呼吸空间
- 底部不要有重要内容贴边

### 方案 B：底部预留文案带

如果希望文案「半嵌入」图片底部，用这种构图：

```
┌──────────────────────────────┐
│                              │
│        主体（产品 + 场景）      │  ← 占据上方 60–70%
│                              │
│ · · · · · · · · · · · · · · ·│  ← 下方 30–40% 留空
└──────────────────────────────┘
   ┌──────────────────────┐
   │ Pet-Friendly Air...  │  ← 文案卡片叠在这里
   └──────────────────────┘
```

- 主体放在**上方 60–70%**
- 底部 **30–40%** 保持干净：虚化的地面、纯色墙面、柔和的渐变都可以
- 底部不要放产品、宠物或重要细节

## 四、导出规格

| 项目 | 要求 |
|---|---|
| 格式 | **JPEG** |
| 质量 | 75–85 |
| 单张体积 | **≤ 300 KB**（最多不超过 500 KB） |
| 如果必须用 PNG | 仅当需要透明背景时，且控制在 1 MB 内 |

> 参考：改造前单张图是 **12–20 MB**（PNG 格式存照片），压缩后是 **300–450 KB**。
> 体积直接决定首页打开速度，而打开速度是 Google 的排名因素之一。

---

## 五、文件命名

用**英文小写 + 连字符**，不要用中文文件名。

| ❌ 不要 | ✅ 建议 |
|---|---|
| `轮播02.png` | `hero-02.jpg` |
| `meower-100-carousel.png` | `hero-mw100-bedroom.jpg` |

中文文件名在网址里会变成 `%E8%BD%AE%E6%92%AD02` 这种乱码，不美观也不利于分享。

2. 首屏布局改成「文案在图下方」或「半嵌入」（按你选的方案）
3. 标题、副标题、按钮全部改为 HTML 真实文本
4. 给每张图补准确的 alt 文字
5. 重新构建、验证首屏字数与图片体积

## 八、顺带一提：如果实在不方便重新出图

我可以直接从现有图片**裁掉左上角带文字的区域**，换一个构图使用。代价是画面比例会变（原图 1800×1012 裁掉左侧后偏竖版），主体位置也不一定理想。

如果重出图成本高，可以先用这个方案顶着，等下次拍摄再替换。
