## 二、为什么搜 "Meower" 找不到

品牌词排名的本质：**Google 需要证据证明「搜 Meower 的人要找的就是 meowerair.com」**。

证据有三个来源：

### 1. 外部提及（决定性因素）

Google 判断"一个品牌是谁"，靠的是**全网引用**。别人提到 "Meower" 并链接到你，Google 才会把这两个东西关联起来。

**你现在一个外部链接都没有**，Google 手里几乎是空的。

### 2. 品牌名已被别人占用

有个开源社交项目也叫 [Meower](https://github.com/nikki-uwu/Meower)，它有 GitHub 仓库、wiki、技术社区讨论——这些是**强信号**。搜 "Meower" 时，Google 认为用户要找的是它。

### 3. 域名不匹配

你的域名是 `meowerair.com`，不是 `meower.com`。Google 不会自动把裸词 "Meower" 关联到 `meowerair.com`。

## 五、目标关键词：别死盯裸词

"Meower" 这个词有歧义且已被占用。真正能带来客户的是**品牌 + 品类**的组合词，竞争小得多：

| 优先级 | 关键词 | 说明 |
|---|---|---|
| 🥇 | `Meower air purifier` | 意图最明确 |
| 🥇 | `Meower dehumidifier` | 同上 |
| 🥇 | `Meower air` | 你最初搜的词 |
| 🥈 | `Meower MW100` / `Meower MW200` | 型号词，转化率最高 |
| 🥈 | `Meower pet air purifier` | 结合定位 |
| 🥉 | `Meower`（裸词） | 最后再攻，需要长期外链积累 |
