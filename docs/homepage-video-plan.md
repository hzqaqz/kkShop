# 首页宣传视频策划方案（Meower）

> 前提：首页刚从 **111MB 图片压缩到 2MB**。视频方案的第一原则是**不能把性能成果毁掉**。

---

## 一、⚠️ 最重要的技术红线

**绝对不要做"自动播放的背景视频"。**

原因：

| 风险 | 后果 |
|---|---|
| 视频文件动辄 10–50MB | 首页从 2MB 变回 50MB，打开又要等十几秒 |
| 抢占带宽 | 首屏图片加载被拖慢，LCP（Google 排名因素）崩掉 |
| 持续解码 | 手机发热、掉电、卡顿 |
| 分散注意力 | 首屏已经有轮播图 + 文案卡 + 按钮，再加动态视频会非常乱 |

**正确做法：「海报图 + 播放按钮」门面模式（facade pattern）**

```
用户看到的是：一张静态海报图 + 一个播放按钮
实际加载的：仅一张图片（约 200KB）
用户点击后：才加载视频
```

这样视频对首屏性能的影响**接近于零**。

## 二、先想清楚：这条视频给谁看

你的首页有两个完全不同的受众，一条视频很难同时打动两边：

| 受众 | 他们关心什么 | 视频该展示什么 |
|---|---|---|
| **B2B 买家**<br>（分销商 / 零售商 / OEM） | 产能、品控、认证、交期、能不能长期合作 | 产线、质检、实验室、认证、装柜出货 |
| **宠物家庭**<br>（终端用户） | 我家猫掉毛、有味道，这东西真有用吗 | 宠物场景、过滤效果实测、静音、颜值 |

**建议首页视频以 B2B 为主、宠物场景为引子**——因为你的商业模式是 B2B（页面上写的是 distributors / retailers / OEM-ODM），首页的转化目标是**询盘**，不是直接卖货给消费者。

## 三、视频拍什么（三个方向）

### 方向 A：产品实测片（最有说服力）

**核心**：用可视化的方式证明"它真的有用"。

可拍的实测镜头：
- **烟雾/粉尘演示**：在密闭箱内释放烟雾，开机器后计时看多久净化完
- **CADR 对比**：MW100（200 m³/h）vs MW200（400 m³/h）同场景对比
- **噪音实测**：分贝仪贴在机器旁，从 1 档到最高档
- **空气质量灯变化**：3 色指示灯从红变绿的过程（特写）

**优点**：不需要真人出镜、不需要外语旁白、制作成本低、全球通用。

### 方向 B：宠物家庭场景片（情绪共鸣）

**核心**：让宠物主人产生"这就是我家"的代入感。

- 猫在床上掉毛、猫砂盆旁边的空气、狗在沙发打滚
- 开机后：光柱效果里能看到被吸走的浮毛（慢镜头）
- 猫狗在净化器旁边安静睡觉（静音暗示）

**优点**：品牌调性最强，和 "Cleaner Air. Happier Pet Homes." 这句 slogan 完全契合。
**注意**：你已经有大量专业宠物场景图（首页三张轮播图、产品页场景图），可以直接复用同一批场景拍视频，风格统一。

### 方向 C：供应链实力片（B2B 转化利器）

**核心**：回答 B2B 买家最大的疑虑——"这家能不能稳定供货"。

- 产线运作、组装工序
- 质检环节、实验室测试设备
- 认证证书（CE / RoHS / ISO 等）特写
- 仓库、装柜、发往海外的画面
- 团队或工厂外观

**优点**：B2B 买家最吃这套，能直接把询盘转化率拉高。
**前提**：如果你有自有工厂或稳定合作的产线可以拍。

## 四、推荐方案：一条 70 秒混合片

一条片子覆盖两个受众，结构上**先戳宠物痛点，再给 B2B 信心**：

| 时间 | 画面 | 目的 |
|---|---|---|
| **0–5s** | 阳光客厅，猫狗玩耍，镜头缓慢推近 | 建立情感，Logo 出现 |
| **5–12s** | 慢镜头：空气光柱里的浮毛、皮屑飘动 | 抛出问题 |
| **12–22s** | MW100 / MW200 启动，360° 进风示意 + 三层滤网剖面动画 | 产品登场 |
| **22–30s** | 空气质量灯红→绿变化，App 界面特写 | 实时反馈 |
| **30–40s** | MD001 除湿机在浴室/衣柜，雾气消散 | 覆盖除湿产品线 |
| **40–52s** | 产线、质检、实验室测试 | 供应链可信度 |
| **52–62s** | 认证徽章、货柜装运、世界地图点亮 | 出口全球 / OEM & ODM |
| **62–70s** | 收尾：Logo + Slogan + 网址 | Cleaner Air. Happier Pet Homes.<br>meowerair.com |

**旁白策略**：用**英文字幕 + 轻音乐**代替真人配音。
- 成本低得多
- 全球市场通用（你面向多个国家，配一种语言都不合适）
- 后期改文案只要换字幕文件

## 五、放在首页哪个位置

| 位置 | 评价 |
|---|---|
| ❌ 首屏轮播图里当背景视频 | 性能灾难 + 和现有文案卡打架 |
| ❌ 首屏加第四个轮播 slide | 视频在轮播里体验很差（切走就停） |
| ✅ **「Why Meower」板块内**，品牌文案右侧 | 位置合理（讲品牌实力时出现），且不占首屏性能 |
| ✅ **「Best sellers」下方**独立一条 | 产品展示后紧接着视频，转化路径顺 |
| ✅ **产品详情页**（另一条，产品实测片） | 最适合放产品演示，用户意图明确 |

**推荐**：首页放在 **「Why Meower」板块**，用品牌文案左侧 + 视频右侧的双栏布局。理由：
1. 那个板块正好在讲"我们是谁、我们有什么能力"，视频是天然补充
2. 不在首屏，不影响 LCP
3. 用户滚到那里说明有兴趣，转化意图更强

## 六、技术实现要点

### 1. 门面模式（Facade）

```html
<!-- 用户看到的是静态海报 + 播放按钮 -->
<button class="video-facade" @click="loadVideo = true">
  <img src="/images/video-poster.jpg" alt="..." loading="lazy" />
  <span class="play-icon">▶</span>
</button>

<!-- 点击后才插入 iframe -->
<iframe v-if="loadVideo" src="https://www.youtube.com/embed/xxx?autoplay=1" ... />
```

好处：首屏只多加载一张 ~200KB 的海报图，**零视频开销**。

### 2. 用 YouTube 而不是自托管

| | YouTube 嵌入 | 自托管 MP4 |
|---|---|---|
| 带宽成本 | 0（Google 出） | 你出，按流量计费 |
| 自适应清晰度 | ✅ 自动 | ❌ 要自己转多码率 |
| **外链价值** | ✅ **描述里放官网链接 = 一条外链** | ❌ 无 |
| SEO | ✅ 有机会进视频搜索 | ❌ 无 |

**注意**：YouTube 是**外链建设清单里的一项**（见另一份文档 P0 第 4 项）。把视频放 YouTube 并嵌入首页，等于一件事做两件——既提升了首页，又拿到了你正缺的外部品牌信号。

### 3. 结构化数据

加 `VideoObject` 结构化数据，有机会在搜索结果里显示视频缩略图：

```json
{
  "@type": "VideoObject",
  "name": "Meower Air Purifiers & Dehumidifiers",
  "description": "...",
  "thumbnailUrl": "...",
  "uploadDate": "2026-10-10",
  "duration": "PT1M10S",
  "contentUrl": "...",
  "embedUrl": "https://www.youtube.com/embed/xxx"
}
```

## 七、SEO 附加价值（对你特别重要）

你现在的头号问题是**零外链**。视频能一次解决好几件事：

| 收益 | 说明 |
|---|---|
| **YouTube 描述放官网链接** | 直接获得一个高权重外部链接 |
| **YouTube 频道名 `Meower`** | 强化品牌关联（Google 拥有 YouTube，信号强） |
| **上传字幕/文字稿** | 视频内容变成可索引文本 |
| **VideoObject 结构化数据** | 有机会拿视频富摘要 |
| **提升页面停留时间** | 用户看视频会停留更久，是正面的参与度信号 |

## 八、一次拍摄，四个用途

拍一条 90 秒的素材，可以剪出：

| 版本 | 时长 | 比例 | 用途 |
|---|---|---|---|
| 长版 | 90–120s | 16:9 | YouTube 主视频、B2B 报价邮件、展会循环播放 |
| 首页版 | 60–70s | 16:9 | 首页嵌入 |
| 社交短版 | 15s | 9:16 竖版 | Instagram Reels / TikTok / YouTube Shorts |
| 静帧截图 | — | — | 产品页配图、社媒封面、邮件头图 |

**社交短版是你获取外链的免费渠道**——15 秒竖版视频发到 Instagram/TikTok，简介放官网链接。

## 九、制作方式选择

| 方式 | 成本 | 适合 |
|---|---|---|
| **手机 + 稳定器自拍** | 几乎为零 | 产线、仓库、装柜这类纪实镜头 |
| **复用现有摄影团队** | 低 | 你已经有一批专业宠物场景图，同一场景补拍视频最省 |
| **外包专业团队** | 中高 | 需要动画（滤网剖面、气流示意）的部分 |

**分模块制作性价比最高**：
- 宠物场景 → 找摄影团队补拍（复用现有场景）
- 产线/质检 → 手机自拍就够（纪实风格反而更真实）
- 动画部分（气流、滤网剖面）→ 用 AE 模板自己做或外包单段

## 附：一句话原则

**视频的价值不在于"首页有个视频"，而在于它同时服务三件事：**
1. 让访客更信任你（B2B 尤其需要）
2. 让 Google 有更多理由认为 "Meower" 是个真实存在的品牌（YouTube + 外链）
3. 不牺牲你已经优化好的加载速度
